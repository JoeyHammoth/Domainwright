A Crusader Kings III mod

Domainwright

Every ruler has a domain limit. Now you hold the dial.

Pre-release 0.1.0-dev — scripted core and the menu are built, not yet battle-tested

Install it Read the source

What it does

Right-click any character, choose Domain Limit…, and nudge the number that decides how many holdings they can personally keep. Because the override is an ordinary domain_limit modifier, vanilla does the rest: the tooltip lists it, the over-limit penalties count it, and the AI acts on it.

Anyone, not just you

Yourself, your vassals, an over-mighty rival. The menu works on any living character.

No AI rewrites

Nothing in the AI is replaced. The game already reads the limit as a statistic, so it simply reads the new one.

Additive, always

No vanilla file is overridden and every identifier is prefixed dlc_. It composes instead of conquering.

The ladder, in your hands

The engine can't take a runtime number in a modifier, so Domainwright expresses your override as a sum of powers of two — one rung per bit. Click a button: the lit rungs are exactly the modifiers that would be on the character.

Override 0 no rungs applied

Range is −63 to +127. Values are clamped, and the effect is idempotent — reapplying always leaves exactly one rung set.

Install

  1. Take the zip

    Download the latest release from GitHub Releases.

  2. Drop it in the mod folder

    Unzip so that descriptor.mod sits at the root of a folder inside your CK3 mod directory:

    Documents/Paradox Interactive/Crusader Kings III/mod/domainwright/

    macOS: ~/Documents/Paradox Interactive/Crusader Kings III/mod/domainwright/ · Linux: ~/.local/share/Paradox Interactive/Crusader Kings III/mod/domainwright/

  3. Enable it in the launcher

    Open Mods, tick Domainwright, and start or load a campaign. Back up the save first — it is a pre-release.

How to play

The Domain Wright

Countess Adela holds 4 holdings. The override is +3 on top of the natural limit.

  • Lower the limit by 5
  • Lower the limit by 1
  • Raise the limit by 1
  • Raise the limit by 5
  • Clear the override

Each click applies the change and reopens the menu, so you can keep clicking. Right-click the portrait of anyone you are allowed to edit — the game rule decides who that is.

Game rules

RuleSettingsDefault
Who may edit Anyone · Player only · Player and realm Anyone
Inheritance None · Heir inherits delta None

Changes that are not the default block achievements, the way vanilla's own domain-limit rule does.

Known issues, honestly

  • Not validated in game yet. The scripted core is written and passes static checks; Milestone 1 is the go/no-go gate.
  • Some governments clamp. A ruler whose government sets domain_limit_max may ignore a raised limit. Nomads, Mandala, Wanua, Ritsuryo and Soryo are the ones to watch.
  • No slider. The interface is buttons and presets on purpose — passing an arbitrary number from GUI to script is a spike, not a promise.
  • Multiplayer unsupported until tested. Back up saves before first use.

Before uninstalling mid-campaign, open the menu and use Clear every override in the world.
